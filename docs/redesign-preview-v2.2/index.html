Color API y accesibilidad

Las respuestas de ejemplo guardadas contienen valores #RRGGBB. La app debería parsear solo ese formato; ausencia o valor inválido usa indicador neutro. Para la propuesta se usan muestras observadas: naranja #ff9500 y verde #029353. La línea 42 queda neutra en esta maqueta porque sus snapshots discrepan para el mismo cliente. La misma línea visible puede tener otro color para otro cliente; antes de implementar, resolver por cliente e identificador API, nunca por el número visible. El color no reemplaza el número ni el check de selección.

Verificación pendiente de contrato: el fixture de selección guardado no tiene la misma estructura que el DTO actual y envía latitud/longitud como texto. Las muestras de color sirven para evaluar el aspecto, no confirman todavía la clave de producción. El informe detalla qué respuesta real y pruebas hacen falta antes de implementar.
